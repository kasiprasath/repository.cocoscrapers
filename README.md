# repository.cocoscrapers

CocoScrapers Module - A Kodi addon module that provides site scrapers for torrent sources.

## Download

Landing page: **https://kasiprasath.github.io/cocotamil2411.github.io/**

Direct download: **[repository.cocoscrapers-1.0.2.zip](https://github.com/kasiprasath/repository.cocoscrapers/raw/main/zips/repository.cocoscrapers/repository.cocoscrapers-1.0.2.zip)**

## Installation

1. Download the repository zip from the landing page or direct link above
2. In Kodi, go to **Settings → Add-ons → Install from zip file**
3. Select the downloaded `repository.cocoscrapers-1.0.2.zip`
4. The CocoScrapers repository will now appear under **Install from repository**
